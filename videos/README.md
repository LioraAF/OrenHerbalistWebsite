# Video library

## Adding Instagram links

Open `reel-links.js`, find the matching video number, and paste the complete
Instagram Reel URL between the quotation marks:

```js
"medicinal-plants-01": "https://www.instagram.com/reel/EXAMPLE/",
```

Empty entries temporarily open the general Instagram profile.

## Video folders

- `medicinal-plants/` — צמחי מרפא
- `foraging/` — ליקוט
- `natural-pharmacy/` — רוקחות טבעית

Use short filenames with lowercase English letters and hyphens, such as
`summer-herbs-01.mp4`. A matching poster can be named `summer-herbs-01.jpg`.
